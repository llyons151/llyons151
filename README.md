I build and run a network of daily guessing games: one shared engine, many fandoms, 400K+ pageviews a month.

| Game | Domain | Description |
|---|---|---|
| **[Rivaldle](https://rivaldle.com)** | rivaldle.com | Daily Marvel Rivals hero guesser. Five modes, accounts, streaks and push notifications. The flagship. |
| **[SoulsDoku](https://soulsdoku.com)** | soulsdoku.com | A sudoku-style grid of bosses from seven Souls games. Fastest-growing site in the network. |
| **[Chainsaw Man-dle](https://chainsawmandle.com)** | chainsawmandle.com | Chainsaw Man character guesser with quote, emoji and blur modes. |
| **MCUdle** | coming soon | Marvel Cinematic Universe guesser. |

<p align="center"><img src="assets/h-quest.svg" width="100%" alt="Current Quest" /></p>

**Locturne** is an iOS app where your apps go to sleep at bedtime and don't wake up until you get out of bed. To unlock them in the morning, walk downstairs, hit a step count, or scan a code in another room. Built with React Native and Expo, and run by a very tired raccoon.

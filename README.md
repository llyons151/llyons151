### 🕹️ The -dle network

I build and run a network of daily guessing games. One shared engine, many fandoms, real traffic.

| | Game | What it is |
|:-:|---|---|
| 🦸 | **[Rivaldle](https://rivaldle.com)** | Daily Marvel Rivals hero guesser. Five modes, accounts, streaks, push notifications. The flagship. |
| 🗡️ | **[SoulsDoku](https://soulsdoku.com)** | Sudoku-style grid of Souls-series bosses across seven games. Fastest-growing site in the network. |
| 🪚 | **[Chainsaw Man-dle](https://chainsawmandle.com)** | Chainsaw Man character guesser with quote, emoji and blur modes. |
| 🛡️ | **MCUdle** | Marvel Cinematic Universe guesser. *Coming soon.* |

### 🌙 Building now: Locturne

An iOS app where your apps go to sleep at bedtime and don't wake up until you get out of bed. Walk downstairs, hit your steps, or scan a code in another room. React Native + Expo, run by a very tired raccoon. 🦝
